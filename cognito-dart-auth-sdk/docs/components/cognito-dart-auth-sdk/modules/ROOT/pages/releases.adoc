== v0.0.6

=== Overview
This release completes the next Cognito operation block by extending the shared request and consumer wrappers through the update, tag, import-job, verification, and user-settings operations.

=== Highlights
* Added SetUserSettings, StartUserImportJob, StopUserImportJob, TagResource, UntagResource, and verification wrappers
* Added UpdateAuthEventFeedback, UpdateDeviceStatus, UpdateGroup, UpdateIdentityProvider, UpdateManagedLoginBranding, UpdateResourceServer, UpdateUserAttributes, UpdateUserPool, UpdateUserPoolClient, and UpdateUserPoolDomain wrappers
* Added public `AortemCognito*` compatibility aliases for the added operation range and SignUp

=== Improvements
* Extended enumerated request and consumer tests so each added operation verifies its Cognito JSON API target.

== v0.0.5

=== Overview
This release completes the next older Cognito ticket batch by adding additional user-pool operation wrappers and aliases on the shared operation executor.

=== Highlights
* Added request and consumer wrappers for the older AdminUserGlobalSignOut through GetIdentityProviderByIdentifier operation range
* Added SetLogDeliveryConfiguration, SetRiskConfiguration, SetUICustomization, SetUserMFAPreference, and SetUserPoolMfaConfig wrappers
* Added public `AortemCognito*` compatibility aliases for the added classes

=== Improvements
* Extended the shared operation builder with generic field support and common Cognito field helpers.
* Added list-field validation for operations requiring non-empty list payloads.
* Covered every added operation target with enumerated request and consumer tests.

== v0.0.4

=== Overview
This release expands the maintained Cognito SDK surface with non-admin user-pool operation wrappers and fluent consumers.

=== Highlights
* Added request wrappers for common non-admin Cognito user-pool operations
* Added matching consumer/builder facades for those operations
* Added public `AortemCognito*` compatibility aliases

=== Improvements
* Exported the new request and consumer surfaces from the package entrypoint.
* Covered AWS JSON API target wiring, required-field validation, service error handling, public exports, and aliases with unit tests.

== v0.0.3

=== Overview
This release hardens the existing admin request surface and keeps the published package metadata cleaner.

=== Highlights
* Corrected admin request validation for device keys, auth flows, and challenge sessions
* Replaced empty integration test files with placeholder `main()` entries
* Reduced publish noise by moving test utilities and excluding generated artifacts

=== Improvements
* Improved validation behavior across admin request wrappers.
* Moved `ds_tools_testing` into `dev_dependencies`.
* Added package/archive excludes for docs and generated example artifacts.

== v0.0.2

=== Overview
This release prepares the stable Cognito package for the Dart `3.11.4` line while aligning the docs and CI surface with the current backend-first package direction.

=== Highlights
* Added a clearer `CognitoAuth` public alias
* Refreshed the direct dependency constraints to current supported releases
* Updated docs and CI to match the maintained sample set

=== Improvements
* Added `CognitoAuth` as a public-facing alias for the primary SDK client.
* Updated the README, examples index, and install guidance to match the current package surface.
* Aligned development and setup-validation CI with the Dart `3.11.4` baseline.

== v0.0.1

=== Overview
This release establishes the first stable package version and focuses heavily on example app polish, readability, and consistency across authentication screens.

=== Highlights
* First stable package release
* Cleaner example app UI and navigation patterns
* Better consistency across auth and MFA example flows

=== Improvements
* Streamlined layout and widget construction across the example Flutter screens.
* Standardized `SnackBar`, `MaterialPageRoute`, loading, and async result patterns.
* Simplified auth-related UI flows for Apple, Google, email and password, MFA, popup, redirect, and OAuth examples.
* Improved home and auth-state screen readability and provider-linking layout consistency.

=== Removed
* Removed the legacy placeholder file from the example app.
