# Cognito Example Apps

Current example directories under `example/`:

- `cognito-dart-auth-sdk-compose-app`
- `cognito-dart-auth-sdk-dart-web-app`
- `cognito-dart-auth-sdk-flutter-desktop-app`
- `cognito-dart-auth-sdk-flutter-games-app`
- `cognito-dart-auth-sdk-flutter-mobile-app`
- `cognito-dart-auth-sdk-flutter-web-app`
- `cognito-dart-auth-sdk-react-app`
- `cognito-dart-auth-sdk-svelte-app`
- `cognito-dart-auth-sdk-vue-app`

Treat these apps as integration references. They are useful for wiring flows and smoke checks, but they are not the backend security boundary for privileged Cognito operations.
